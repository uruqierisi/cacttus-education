  ## 9. RESPONSIVE RULES

  **Desktop (1440):** as specified above. Content max-width 1200. Grids: programs 2-col, trainings 3-col, business 2×2, projects 3-col, articles 3-col,
  people 4-col.

  **Mobile (390):**
  - Navbar collapses to logo left + hamburger right, height 60. The `Apliko tani` button moves into the mobile menu as a full-width button pinned to the
  bottom of the overlay.
  - Top banner text shrinks to `Caption`; drop the right-hand "Apliko tani" link, keep the "×".
  - All multi-column grids become 1 column, except people grids which become 2 columns and the hero stat strip which becomes a 2×2 grid.
  - Hero: image below the text block; headline uses the mobile `Display` size; the rotating word still animates and still reserves fixed width.
  - Success-stories carousel shows 1.2 slides with a peek of the next, horizontal drag plus dots; arrows hidden.
  - Filter chip rows become horizontally scrollable single rows with a fade mask at the right edge.
  - Semester accordions stay full-width; the horizontal 4-step rail becomes a vertical stepper on the left of the accordions.
  - Footer columns stack in order: brand → Navigimi → Rreth nesh → Rrjetet Sociale; bottom bar centered, stacked.
  - All tap targets ≥ 44×44. Section padding drops to 64/64. Side margins 20.

  ## 10. ACCESSIBILITY

  - All text meets **WCAG AA** contrast: body text ≥ 4.5:1, large text and meaningful UI elements ≥ 3:1. Never place `color/primary/300` or lighter behind
  white text. Muted text uses `color/neutral/500` on white minimum.
  - Every interactive component has a distinct **focus** state: 3 px ring `rgba(142,68,173,0.35)` plus a 1 px `color/primary/500` border.
  - Never signal state by color alone: selected filter chips also change weight to 600; error fields also show an icon and a message; the "Regjistrime të
  hapura" chip pairs its green dot with the word.
  - Minimum body text size 16; never below 13 anywhere.
  - Form fields always have a visible label above the field — placeholders are never the only label.
  - Image slots include an `alt`-style description in the layer name, e.g. `PH/Foto studentësh — hero — grup studentësh në laborator`.
  - Provide a "reduced motion" note on `00 Cover`: all decorative motion (typewriter, carousel autoplay, scroll reveal) must be disable-able in build.
