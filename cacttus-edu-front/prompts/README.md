# Prompts

This folder holds production-ready system prompts generated by the **Prompt Architect** slash command, one file per agent. Each file contains only the finished system prompt — no extra commentary — so it can be copied straight into whatever tool you're configuring (Claude, GPT, a custom agent framework, etc.) or referenced directly by path.

## Generating a new prompt

Run the slash command from a Claude Code session in this repo:

```
/prompt-architect
```

You can optionally pass a starting description to skip the first question:

```
/prompt-architect a customer support agent for our billing SaaS product
```

Claude will then:

1. **Interview you** about the agent you want to build — its role, audience, tone, input/output format, constraints, tools/integrations, edge cases, success criteria, and any example interactions. It asks follow-ups instead of guessing when your answer is vague, and won't re-ask anything you already told it.
2. **Draft the system prompt**, structured with clearly labeled sections (role, objective, tone, process, dos/don'ts, output format, few-shot examples, edge cases, clarifying-question behavior, and reusable variables where relevant), following standard prompt-engineering practice: direct language, positive instructions stated before prohibitions, role and constraints near the top, and step-by-step reasoning encouraged where the task warrants it.
3. **Deliver the result**: the full prompt in a pasteable markdown code block, plus a short note on the choices and assumptions made — and save the same prompt to `prompts/<agent-name>.md` in this folder.

## Reusing this folder

- Run `/prompt-architect` again any time you want to design a new agent — it's stateless across runs and doesn't assume continuity with earlier ones.
- To revise an existing agent's prompt, mention the file by name when you run the command; if you don't, and a file with the same slug already exists, Claude will ask before overwriting, versioning (`<agent-name>-v2.md`), or renaming.
- Files here are plain markdown and safe to hand-edit afterward — the generator produces a strong first draft, not a locked artifact.
